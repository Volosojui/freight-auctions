# MobX store pattern

Клиентский UI-state держим точечно на MobX. Правила для этого проекта:

- **Серверное состояние — только TanStack Query.** MobX не дублирует данные с бэкенда
  (список аукционов, детальная, ставки). MobX — для локального UI-состояния:
  черновик фильтров, состояние открытия/сабмита формы ставки, тосты и т.п.
- **Стор — это фабрика, а не глобальный синглтон.** Экспортируем `createXxxStore()`,
  чтобы состояние можно было изолировать в тестах и не тянуть побочки между рендерами.
  Единичные общеприложенческие сторы (например, тосты) создаются один раз в `shared`.
- **Реактивность — через `observer`** из `mobx-react-lite`. Любой компонент, читающий
  observable-поля стора, оборачивается в `observer(...)`.
- Действия помечаем `action` (через `makeAutoObservable`), вычисляемые — `computed`.

Пример — см. `src/shared/ui/toast/toast-store.ts` и `toast.component.tsx`.
