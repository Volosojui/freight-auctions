## Context

Data-layer и детальная готовы. `GET /auctions/{auctionUuid}/bets` возвращает `{ bets: BetItem[] }`; у `BetItem` двойные цены, `place` (nullable), `is_win`, `is_rejected`, `cancel_reason` (пустая строка если нет), контакт/организация перевозчика. Флаг `hide_bets_history` живёт в детальном DTO. См. `proposal.md` — Why.

## Goals / Non-Goals

**Goals:**
- Согласованность со скрытием истории: раздел ставок не должен «протекать» при `hide_bets_history`.
- Чистый маппер строки ставки под unit-тесты (нормализация пустых строк/nullable).

**Non-Goals:**
- Установка ставки (→ `place-bet`); здесь только просмотр.
- Пагинация ставок — контракт отдаёт весь список одним ответом.

## Decisions

**Размещение — вкладка на детальной.** Ставки показываем как вкладку/раздел в `auction-detail` (общий маршрут `/auctions/$auctionUuid`), а не отдельный top-level маршрут: так проще шарить `hide_bets_history` из детального DTO и переиспользовать загруженный аукцион. Доступность вкладки определяет `canViewBets` из gate-маппера детали. _Альтернатива:_ отдельный маршрут — избыточно, дублировал бы загрузку флага.

**Query-ключ.** `['auction', auctionUuid, 'bets']`. Запрос ставок включается только когда история не скрыта (`enabled: canViewBets`), чтобы не дёргать эндпоинт впустую.

**Число участников.** Выводим из числа релевантных ставок (или отдельного поля, если оно есть в ответе store); считаем в маппере, не в компоненте.

**Маппер строки.** Чистый `BetItem -> BetRowVM`: нормализует пустую `cancel_reason`/пустой телефон в «нет», разбирает `place`=null, форматирует цены с/без НДС, флаги `is_win`/`is_rejected`/`is_counter`. Покрыт unit-тестами.

**FSD-раскладка.** `widgets/bets-list` (список + состояния) внутри `pages/auction-detail`; `entities/bet` (маппер + строка `*.component.tsx`).

## Risks / Trade-offs

- [Утечка данных при `hide_bets_history`] → Запрос `enabled` по `canViewBets`; UI рендерит «скрыто» до и вместо любого списка.
- [Пустая строка vs null в контракте] → Нормализация в маппере с явными тестами (`cancel_reason=""`, `place=null`, пустой телефон).
- [Двойные цены путаются] → Обе цены явные, метки «с НДС»/«без НДС» в VM.
