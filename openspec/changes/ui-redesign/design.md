## Context

Текущее оформление — минимальный custom CSS с CSS-переменными в `src/app/styles/global.css` и небольшой набор компонентов `shared/ui` (Button/Card/Skeleton/Spinner/ToastHost). Разметка использует `data-testid`, роли и текстовые метки, на которые опираются 93 unit/integration + 17 e2e теста. Ограничения: без новых зависимостей (эволюция токенов), сохранить наблюдаемое поведение и селекторы тестов. Направление подтверждено через `/ui-ux-pro-max`: Minimalism / Swiss, B2B data-focused. См. `proposal.md` — Why.

## Goals / Non-Goals

**Goals:**
- Единая токен-система (палитра, типографика, spacing, radius, elevation) и переоформление всех экранов в аккуратном data-focused виде.
- Светлая/тёмная темы на токенах с переключателем и сохранением.
- Доступность (AA-контраст, focus-visible, клавиатура, ARIA, Esc/focus-trap в модалке).

**Non-Goals:**
- Любые изменения бизнес-логики, потоков, контракта, роутов, данных.
- Новые зависимости, UI-библиотеки, внешние шрифты (по умолчанию системный стек).

## Decisions

**Арт-направление (ui-ux-pro-max): Minimalism / Swiss, navy + blue-CTA.** Чистые поверхности, сетка, высокий контраст, плотность данных, табличные цифры. Анти-паттерны: игривость, AI-градиенты, лишние тени.

**Токен-архитектура.** Семантические CSS-переменные на `:root` (светлая по умолчанию). Тёмная тема — переопределение тех же токенов в двух местах: `@media (prefers-color-scheme: dark)` (guarded `:root:not([data-theme="light"])`) для системного дефолта и `:root[data-theme="dark"]` для явного выбора (чтобы toggle побеждал в обе стороны). Никакой цвет не определяется только в media-блоке. Сохраняю существующие имена (`--bg`, `--surface`, `--border`, `--text`, `--text-muted`, `--primary`, `--danger`, `--success`, `--radius`, `--shadow`) и добавляю шкалы.

Светлые токены (Swiss / slate):

```
--bg:#F8FAFC  --surface:#FFFFFF  --card:#FFFFFF
--border:#E2E8F0  --text:#0F172A  --text-muted:#475569
--primary:#0369A1  --primary-hover:#075E8C  --primary-contrast:#FFFFFF
--brand:#0F172A  --ring:#0369A1
--success:#15803D  --danger:#DC2626  --warning:#B45309
--badge-bg:#EEF4F9  --badge-fg:#0B4A6F
```

Тёмные токены (десатурированные, не инверсия; контраст проверяется отдельно):

```
--bg:#0B1220  --surface:#111A2B  --card:#131D30
--border:#25324A  --text:#E6EDF6  --text-muted:#9FB0C7
--primary:#38A3D9  --primary-hover:#57B6E6  --primary-contrast:#08131F
--brand:#E6EDF6  --ring:#38A3D9
--success:#4ADE80  --danger:#F87171  --warning:#FBBF24
--badge-bg:#12233A  --badge-fg:#9AD1F0
```

**Типографика.** Системный стек (`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`) — без внешних шрифтов. Данные и цены — `font-variant-numeric: tabular-nums` для стабильных колонок. Шкала: `--fs-xs:12 --fs-sm:13 --fs-md:14 --fs-lg:16 --fs-xl:20 --fs-2xl:26`; base 14–16, line-height 1.5; веса 400 body / 500 label / 600–700 heading.

**Шкалы.** Spacing (плотная, 4px-ритм): `--sp-1:4 --sp-2:8 --sp-3:12 --sp-4:16 --sp-6:24 --sp-8:32`. Radius: `--r-sm:6 --r-md:8 --r-lg:12 --r-pill:999`. Elevation (сдержанная): `--e-1:0 1px 2px rgba(2,6,23,.06)`, `--e-2:0 4px 12px rgba(2,6,23,.10)`, `--e-modal:0 16px 48px rgba(2,6,23,.28)`.

**Переключатель темы.** Небольшой модуль в `shared` (`theme` controller): читает `localStorage['theme']` (`'light'|'dark'`), иначе следует системе; ставит `data-theme` на `<html>`; экспортирует React-хук + кнопку-иконку в шапке app shell. Без новых зависимостей. Это точечный клиентский UI-state (допустимо на React state/маленький модуль; не дублирует Query/router).

**Компоненты (направление).**
- *Card / surface*: `--card` фон, 1px `--border`, `--r-md`, `--e-1`; hover-подъём только у кликабельных.
- *List — плотные строки/«таблица»*: карточки аукционов компактнее, чёткая иерархия (номер/маршрут крупнее, мета — muted, цены — tabular, выравнивание по правому краю числовых).
- *Badges* — статусы аукциона/торгов цветовыми токенами + текст (не только цвет): «моя ставка», победитель, отменён.
- *Buttons* — primary (CTA blue) / secondary (outline) / ghost; чёткие hover/active/disabled/focus-visible; один primary на экран.
- *Inputs / filters* — видимая метка, helper, focus-ring, ошибка под полем; чекбокс-группы фильтров как chips.
- *Modal (ставка)* — центрированная, scrim `--e-modal`, focus-trap, автофокус на цену, Esc-close, возврат фокуса; анимация из триггера с учётом reduced-motion.
- *Tabs (детальная)* — активная вкладка с индикатором и `aria-selected`.

**Доступность.** `:focus-visible` кольца 2px `--ring` на всех интерактивных; контраст пар ≥4.5:1 (проверить в обеих темах); `color-not-only` для статусов; ARIA-имена у иконочных кнопок; модалка — focus-trap + Esc + возврат фокуса; `@media (prefers-reduced-motion: reduce)` отключает переходы.

**Стратегия без регрессий.** Правки в основном CSS + минимальная разметка. **Сохраняю все `data-testid`, роли и проверяемый тестами текст** (лейблы статусов, «Участников», «Ставка принята» и т.п.). Новые обёртки/классы не ломают селекторы. После каждого экрана — прогон `lint`/`vitest`/e2e. Добавляю тесты: переключение темы + persist, Esc-close модалки, наличие focus-стилей/`aria`.

## Risks / Trade-offs

- [Смена разметки ломает селекторы тестов] → Держать `data-testid`/роли/тексты; прогонять свиту поэкранно; правки — аддитивные обёртки/классы.
- [Тёмная тема с недостаточным контрастом] → Проверять пары контраста отдельно для dark; токены десатурированные, не инверсия.
- [Плотность вредит touch/читаемости] → 4/8px-ритм, focus-target ≥24px (web), не жать ниже читаемого; проверка на 375px.
- [Мерцание темы при загрузке (FOUC)] → Ставить `data-theme` максимально рано (инлайн-скрипт в `index.html` до рендера) по сохранённому/системному значению.
- [Соблазн расширить scope на анимации] → Ограничиться 1–2 ключевыми переходами на вид, `prefers-reduced-motion`.

## Revision v2 (после ревью)

Первый проход не понравился: не хватало иконок, фильтр занимал колонку, местами тесный вертикальный ритм. Палитру оставляем (navy + blue), меняем структуру и плотность.

**Иконки — `lucide-react`.** Небольшая tree-shaken зависимость, единый тонкий stroke-стиль. Применяем в: брендинге/шапке, кнопке «Фильтры», полях фильтров, мета-строках карточки (маршрут/даты/груз/цена), primary-действиях, статусах ставок (победитель/отменён), тостах, переключателе темы. Декоративные иконки рядом с текстом — `aria-hidden`; иконочные кнопки — с `aria-label`.

**Фильтры → slide-over drawer.** Убираем колонку `auctions-page__filters`; список — на всю ширину. В панели над списком: кнопка «Фильтры» (с иконкой и счётчиком активных), рядом — активные фильтры чипсами с удалением. Клик открывает выезжающую панель (drawer) справа со scrim, focus-trap, Esc-close (переиспользуем паттерн модалки). Поведение фильтров (синхронизация в URL, Zod-fallback) не меняется — меняется только их размещение. Drawer работает одинаково на desktop и mobile.

**Вертикальный ритм.** Увеличиваем межстрочные/межсекционные отступы: сетка списка `gap` крупнее, мета-строки карточки просторнее, строки ставок и секции детальной — больше `padding`/`gap`. Добавляю токены ритма секций (16/24/32) и применяю их.

**Не-регрессия.** Поведение и селекторы сохраняются. Существующие тесты, которые взаимодействуют с фильтрами (integration list), адаптируются механически (сначала открыть drawer), без изменения сути проверок. Компонентный тест фильтров рендерит форму напрямую — не затрагивается.
