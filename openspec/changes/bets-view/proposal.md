## Why

Пользователю нужно видеть историю ставок по аукциону: кто участвует, по какой цене, кто лидирует/победил, какие ставки отменены и почему. Нужна страница/вкладка ставок по `GET /auctions/{auctionUuid}/bets` с учётом флага `hide_bets_history`. Опирается на `api-contract`/`mock-backend` и на точку входа из `auction-detail`.

## What Changes

- **Список ставок** (вкладка/страница) по `GET /auctions/{auctionUuid}/bets`.
- Отображение: список ставок, количество участников, цена с НДС / без НДС, перевозчик (организация/контакт), место в рейтинге (`place`), признак победителя (`is_win`), признак отменённой ставки (`is_rejected`) и причина отмены (`cancel_reason`, если есть).
- **Empty state**, если ставок нет.
- **Состояние «история скрыта»**, когда `hide_bets_history` истинно (список недоступен, показывается пояснение).
- **ViewModel-маппер** `BetItem` → пропсы строки ставки (+ unit-тесты).

## Capabilities

### New Capabilities
- `bets-view`: просмотр истории ставок аукциона — загрузка по `GET /auctions/{auctionUuid}/bets`, отображение ставок (цена с/без НДС, перевозчик, место, победитель, отмена+причина), количество участников, empty-состояние и состояние скрытой истории по `hide_bets_history`.
